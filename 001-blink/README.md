# Project: Blink an LED on Arduino Uno R3 Board
## About
This project highlights my learning process on how to blink an LED at different stages.

The stages include:
1. Using Arduino Framework.
2. Using Memory Mapped Register, while still using setup() and loop().
3. Completely avoiding Arduino Framework code and using main() function, but still using Arduino IDE.
4. Using AVR tools instead of Arduino IDE.
